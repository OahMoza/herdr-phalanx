01 · 根本分歧

同一台机器，两种写入契约

两个 SQLite 数据库，各自独立。不共享连接，不共享事务，不共享写入者。它们唯一的"桥"是未来会建的 references/agent-bus-phalanx-bridge.md — 当前明确在 scope 之外。

🔒 Phalanx · 单写者 per Run

  • Run 表有 coordinator_id
  • 每次 write 校验 owner
  • claim Task + create Dispatch 一条 transaction
  • 重复终态被拒绝（幂等）

🔄 Bus · 多写者 row-level

  • 没有 owner 概念
  • 每行有 lease_id
  • state-change 必须带完整 lease triple
  • lease 到期 → reaper 回收
选择规则：需要可靠跟踪"谁派了哪次活、结果怎样" → Phalanx。
只需要"把消息放到某类 agent 面前" → Agent Bus。
02 · Phalanx 编排

单一 Coordinator 的 可靠执行闭环

Run → Task → Dispatch → Event 四层模型 + capability observation + Gate 决策门。每条状态变更有解析的 TASK_COMPLETE 作为终态证据，idle/done 不算成功。

# 一次完整的 Phalanx 生命周期（CLI 视角） python db/phalanx_db.py run-create --objective "修复登录" --workspace w9 → run_id = run_c2db01d6 python db/phalanx_db.py task-add --run run_c2db01d6 --spec "改登录接口" --role Developer → task_id = task_a1b2c3 python db/phalanx_db.py task-claim --task task_a1b2c3 --coordinator hermes-main --kind omp --agent-name dev-1 → dispatch created · attempts=1 · task=running herdr agent prompt dev-1 "<p> ... <work>" → herdr agent wait --until idle,done,blocked,timeout python db/phalanx_db.py dispatch-complete-from-output --dispatch disp_4060b17a --text "## TASK_COMPLETE ..." → Task done · dependent Tasks 自动 ready
硬规则：idle 和 done 只表示"现在应读输出"。只有解析的 TASK_COMPLETE 才能正常完成 Dispatch。缺报告 / blocked / unknown / timeout → 证据化 blocked 状态。
03 · Agent Bus 队列

N:N 竞争消费的 lease 状态机

Producer 只管 enqueue，Worker 只管 claim。Route 按 agent_kind + profile 路由，有 max_in_flight 并发上限。lease 到期自动回收，late result 永不覆盖活跃 lease。

# Agent Bus 生命周期（CLI 视角） python db/agent_bus.py route-set --agent-kind omp --max-in-flight 2 --default-lease-seconds 300 → route created · enabled python db/agent_bus.py enqueue --caller phalanx-bridge --agent-kind omp --payload '{"instruction":"..."}' → msg_abc123 · status=pending python db/agent_bus.py worker-loop --worker-id w1 --agent-kind omp --agent-name omp-dev-1 → claim → build envelope → herdr agent prompt → heartbeat → {claimed:true, delivered:true, lease_id:lease_xyz} # Worker 在 TUI 内调用： python db/agent_bus.py complete --id msg_abc123 --worker-id w1 --lease lease_xyz --result-file result.json --raw-report-file raw.txt → status=succeeded · callback triggered (if any) python db/agent_bus.py result-ack --caller phalanx-bridge --id msg_abc123 → result_acked_at set · archived
lease triple = (id, worker_id, lease_id)。任何 state-changing 命令必须带完整 triple。
late result（lease 已过期的 complete/fail）→ 记录为 Event，永不覆盖活跃 lease 的状态。
04 · 三层拆分

为什么把 Bus 拆成 Core / Adapter / CLI

原来的 db/agent_bus.py 是 1114 行的上帝模块：业务逻辑 + SQLite + Herdr 专属知识 + argparse 全混在一起。一次跨平台移植要动全部。拆完之后 Core 跨平台、Adapter 替换、CLI 形状保留。

05 · 受限信封

Worker 只能看到 4 个命令

lease prompt 是 Bus 给 TUI Worker 的"工作证"。它明确列出 4 个允许命令、5 个禁止命令，并绑定当前 lease_id。Worker 无法 enqueue、无法 claim、无法操作 route。

# 实际发送给 Pi 的 lease prompt（节选） # Bus Lease (RESTRICTED) You hold exactly ONE Bus Message. Do NOT call enqueue or claim. Use ONLY the commands listed in this prompt. ## Message - id: msg_81b07062a3 - agent_kind: pi - profile: local - attempts: 2 - lease_id: lease_PoO3fPNHuwwvKyJnulivQ54iEhASY3kP ## Payload ```json { "instruction": "Acknowledge with AGENT_BUS_OK only" } ``` ## Allowed Commands Set WORKER_ID=<your-herdr-agent-name> and ARTIFACT_DIR=~\.herdr-phalanx\runs\agent-bus\msg_81b07062a3\attempt-2 (create the directory first), then run exactly one of: 1. python db/agent_bus.py heartbeat --id msg_81b07062a3 --worker-id ${WORKER_ID} --lease lease_PoO3fPNHuwwvKyJnulivQ54iEhASY3kP 2. python db/agent_bus.py complete --id msg_81b07062a3 --worker-id ${WORKER_ID} --lease lease_PoO3fPNHuwwvKyJnulivQ54iEhASY3kP --result-file ${ARTIFACT_DIR}/result.json --raw-report-file ${ARTIFACT_DIR}/raw.txt 3. python db/agent_bus.py fail --id msg_81b07062a3 --worker-id ${WORKER_ID} --lease lease_PoO3fPNHuwwvKyJnulivQ54iEhASY3kP --reason ${REASON} --raw-report-file ${ARTIFACT_DIR}/raw.txt 4. python db/agent_bus.py cancelled --id msg_81b07062a3 --worker-id ${WORKER_ID} --lease lease_PoO3fPNHuwwvKyJnulivQ54iEhASY3kP --reason ${REASON} --raw-report-file ${ARTIFACT_DIR}/raw.txt ## Forbidden - enqueue, claim, route-set, route-delete, worker-register - Any other CLI subcommand of agent_bus.py not listed above
信封里的 flag 名必须和实际 CLI 完全一致。Pi 在第一次 smoke 里就挑出了 --message-id vs --id 的不匹配 — 修了。
