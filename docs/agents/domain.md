# Domain Docs

This repository has one domain context.

Before changing domain behavior, read root `CONTEXT.md` when it exists and read relevant records in `docs/adr/` when they exist. If these documents do not exist, continue without creating placeholders. Domain-modeling work creates them only when a term or hard-to-reverse decision is resolved.

Use the terms defined in `CONTEXT.md` in issues, specifications, tests, and implementation notes. If a needed term is absent, record the gap for domain modeling rather than silently creating synonyms.
