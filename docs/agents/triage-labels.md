# Triage Labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | Reporter information is required. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an autonomous implementation Agent. |
| `ready-for-human` | `ready-for-human` | Human implementation is required. |
| `wontfix` | `wontfix` | The issue will not be implemented. |
